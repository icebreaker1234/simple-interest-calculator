# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Please open an issue to describe a proposed change or report a problem. For code changes, create a focused branch, explain the change in your pull request, and include clear steps to reproduce any fixed bug. Keep the calculator easy to run in a standard Bash environment and avoid adding unnecessary dependencies.

By submitting a contribution, you agree that it may be distributed under the project's Apache License, Version 2.0.
